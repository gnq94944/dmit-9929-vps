## 9929 是什么，为什么同叫 9929 差距能这么大

AS9929 是联通旗下的 CUII 精品网，业内习惯拿它跟电信 CN2 GIA 对照。三网回程的走法大致是这样：电信用户回国先走联通 9929，再接电信 163 骨干；联通用户直连 9929；移动用户走 9929 后接移动 CMI。绕路少，晚高峰丢包比普通国际 BGP 线路低。

这条线解决的是“回国这一段稳不稳”，跟 IP 属性是两回事。很多商品页把“9929 原生 IP VPS”写成一个整体，实际是两个独立维度：线路决定延迟和丢包，IP 段决定 TikTok、Netflix、ChatGPT 这些平台把你识别成本地用户还是机房用户。原生 IP 指 IP 段归属地和机房所在地一致；双 ISP 住宅 IP 再进一步，ASN 和 Company 字段都被识别成 ISP 类型，风控更宽松。双 ISP 也不保证一定解锁成功，平台风控是动态的，某个 IP 段被滥用一段时间后会临时降级。

9929、4837、CN2 GIA 三条线路的分工大致是这样。

| 线路 | 强项 | 代价 |
| --- | --- | --- |
| 9929（联通 CUII） | 晚高峰稳，丢包低，三网回程都受益 | 带宽普遍给得小，常见上限 100Mbps，单价高 |
| 4837（联通 A 网） | 带宽能拉到 300Mbps 甚至 1000Mbps，单价低 | 晚高峰延迟波动比 9929 明显 |
| CN2 GIA（电信） | 电信方向回程质量更高 | 价格最高，联通和移动用户受益不如电信明显 |

要稳、能接受小带宽，选 9929。要跑量、能忍晚高峰波动，选 4837。人主要在国内电信、预算够，选 CN2 GIA。

还有一个前排文章常一句话带过的点：同样是 9929，不同商家接的上游不一样。业内有一种说法，接 Cera 的 9929 和接 QN 的 9929，晚高峰表现有差别。这个说法没有公开的量化对比，但方向值得参考：线路名只说明走哪张网，不说明接入点在哪、上游是谁、机房负载控制得怎么样。挑 9929 VPS 时，商家有没有自有 ASN、IP 段是不是自己的、机房在哪个城市，这三样比“9929”三个字更能决定实际体验。
